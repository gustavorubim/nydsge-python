# M6 fixed-default ss104 parity and workflow

The public ss104 specification is implemented on `ss104-port`: **84 endogenous
states, 110 total states, 48 shocks, 28 observables, 26 pseudo-observables,
130 parameters and 29 regimes**.
M2-M5's dated parameter calibration is integrated with M1's canonical solves,
temporary-policy recursion and forward expectations. All tests use fixed values.

## Native API

```python
from nydsge.models import Model1002
from nydsge.solve import compute_system
from nydsge.ss104_workflow import forecast_ss104

model = Model1002("ss104")  # forecast start 2026Q3; n_ant=6
system = compute_system(model)
result = forecast_ss104(
    model, system=system, data=transformed_history,
    horizon=40, cond_type="full", history_method="smoothed",
)
```

`transformed_history` is a pandas DataFrame with a quarterly PeriodIndex or a
`date` column and all 28 named observable columns. Missing inputs stay NaN.
History must reach 2026Q2; observations at/after 2026Q3 are conditional quarters.
Full conditioning uses GDP, core PCE, spread, nominal rate and long rate, plus
any supplied expected-FFR observations. Semi conditioning omits GDP/core PCE.
Conditional measurement errors activate only in regime 28, with sigma_condgdp
2*sigma_gdp and sigma_condcorepce 1.25*sigma_corepce. Conditional states and
observables are returned separately; a one-quarter condition leaves 39 future
quarters from the requested 40-quarter horizon. There is no optimization or
posterior sampling in this API. `forecast_one(..., input_type="mode")` dispatches
to the same workflow; other ss104 input types fail explicitly.

The wrapper initializes gaps to -.125/-12 in 2020Q2 only, retains their half-life
10 laws throughout history, and masks observed FFR/OIS during the mechanical
2020Q4-2021Q4 ZLB, as `post_covid_data_mods` does. GDP/inflation COVID quarters
remain observations. Anticipated Taylor shock process variances are zero before
the 2008Q4 historical ZLB. The filter carries states across regime boundaries
and excludes presample periods from scoring. The smoother uses deterministic
Durbin/Koopman means/covariances when data are supplied, avoiding a pseudoinverse
of the singular state covariance. An independent stacked Gaussian calculation
checks its means and covariances, including missing data and changing regimes.

`forecast_linear_system(..., regime_indices=...)` also supports M1's regime
container directly. `nydsge.survey_ffr` parses official SME/SPD workbooks and
merges available 1-6Q paths into transformed history. It requires publication
dates, converts annual fractions to quarterly percentage points and does not
interpolate absent horizons. Missing nonpublic OIS/older PDF-only data are not
filled with substitute observations.

## Source oracle and numbers

The committed `tests/fixtures/ss104_default_oracle.h5` is an actual Julia export
at defaults, produced by `tools/oracle_julia/export_ss104.jl`. It covers all
canonical/system matrices and parameter values for every regime, a 27-quarter
controlled history (2019Q4-2026Q2), filtering, deterministic Durbin/Koopman
smoothing, a 40-quarter unconditional forecast, and one full conditional quarter
with GDP=.65/core PCE=.70 and six supplied FFR expectations, followed by a
39-quarter forecast. The data are a numerical replay case, not a release vintage.
Python never imports Julia or reads the oracle in production.

References are DSGE.jl **c09dfe881f8809f65b8c0f08a761ec6cc456a6fb** and
StateSpaceRoutines.jl **794fb02ff45a62537d8d5d037c1d12b3aa7e4574**.
The source checkout was clean. Julia **1.8.5** bootstraps package types from
`tools/oracle_julia/Manifest.toml`, then overlays the cloned model, settings,
policy, solve, measurement and forecast methods. The cloned StateSpaceRoutines
filter/smoother files run in an isolated module. This bypasses the upstream
ModelConstructors/SMC dependency incompatibility with installed Julia 1.11/1.12;
the economic methods and calibration are not rewritten in the oracle. The
exporter filters parsed type declarations, including doc wrappers, rather than
changing the reference files. All comparisons permute axes by state, shock,
equation and observable names, and verify all 130 parameter names/values.

Including the conditional quarter: Julia **-24.886624714156007**, Python
**-24.886624578812913**. Predicted/filtered covariance maximum absolute errors
are 1.16316e-4 / 1.11634e-4 under the large COVID variance scale. Smoothed observed
row reconstruction residuals are at most 2.06062e-8. The full machine-readable
per-regime results are in [ss104_parity.json](ss104_parity.json).

Tests assert every regime's matrix errors <=5e-10 (canonical matrices/QQ/EE
<=1e-12), likelihood errors <1e-6, forecast state errors <1e-6, forecast
observable errors <1e-7 and smoother mean errors <5e-6. These absolute float64
gates accommodate the amplification of tiny solver differences by COVID sigmas
up to 400. The M1 oracle and exact one-regime regressions still run.

All 26 default pseudo-observable rows are checked, including PseudoGDP,
PseudoCorePCE and the econometrician's rate gap. The Python gap row names
`pgap_t`/`ygap_t` retain the established API and map to Julia's `pgap`/`ygap`.

One upstream convention matters: default `solve_gensys2!` freezes predictable
equations at the first ZLB regime unless `set_pgap1` is present. Consequently
RRR's rm_sh loading stays 1 in regimes 8-9 even though raw eqcond removes that
innovation there. The port preserves that default solve convention; canonical
tests compare raw equations separately. It also skips the steady-state DD
adjustment under the temporary rate rule, as the source does.

## Reproduction

```text
julia --startup-file=no --compiled-modules=no --project=tools/oracle_julia tools/oracle_julia/export_ss104.jl DSGE_ROOT SSR_ROOT outputs/ss104-oracle.h5
python tools/oracle_julia/compare_ss104.py outputs/ss104-oracle.h5 --out outputs/ss104-parity.json
python -m pytest tests/test_ss104.py tests/test_survey_ffr.py tests/test_regimes.py
```

Use Julia 1.8.5 for the existing pinned package environment and a writable local
`JULIA_DEPOT_PATH`; this session used `outputs/julia-depot` followed by the
read-only existing depot. `OPENBLAS_NUM_THREADS=1` makes these small matrix
tests faster on this Windows machine. The fixture is compressed losslessly;
no entries are rounded, zeroed or replaced with Python results.

M6 certifies the **public fixed-default model and controlled replay**. It does
not certify the unpublished FRBNY posterior, historical internal OIS inputs,
production data vintage or unpublished conditioning/markup changes. M7 remains
unchecked. No ss104 estimation or MCMC was used to generate these artifacts.

Final validation: **549 tests passed, 4 optional-backend skips**; Ruff lint and
format checks passed. The branch stayed `ss104-port`; main remained
`6716227be0ed573cd45f6f04fd38cb15a5807c37`. No push was performed.
